# Dhurandhar - Python Text-Based Action Thriller Game

An interactive, branching narrative game built entirely in Python. Players take on high-stakes operations, managing psychological meters like **Trust Levels** and **Anger Levels** while navigating dangerous underworld conflicts.

## 🌟 Features
* **Dual Protagonists:** Play from two completely different perspectives:
  * **Hamza Ali Mazari:** Navigate underworld politics, secure trust, and survive betrayal.
  * **Major Iqbal:** Lead tactical operations, execute high-stakes conspiracies, and hunt targets.
* **Dynamic Mechanics:** Features real-time state tracking (Trust and Anger percentages) where a single wrong choice triggers a terminal game-over or a narrow escape.
* **Branching Storylines:** Multiple distinct missions per character with unique win/loss conditions.
* **Input Sanitization:** Uses advanced string handling (`.lower().strip().title()`) to prevent user input formatting crashes.
